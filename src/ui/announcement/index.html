关于响应路由字段的一点观察

目前收集到的一些案例表明，发生降级的账户在网页端进行 Chat 会话时，响应中会缺少 resolved_model_slug 字段，只能通过 server_ste_metadata.model_slug 识别路由信息；而响应中存在 resolved_model_slug 字段的账户没有发生降级。

以上仅是目前有限样本中的观察，尚不足以将字段是否存在作为判断账户是否降级的通用标准。

欢迎分享你的真实情况

目前的样本量还比较有限，因此我发起了一次投票。如果你愿意，欢迎根据自己账户的真实使用情况参与，帮助补充样本。无论你的账户是否出现过降级，你的反馈都很有价值。感谢你的时间与支持。
